### ⚙️ 2. Un moteur “ENGINE*
- Bash : *core/engine.sh*
- Un moteur qui :
   - charge les modules  
   - gère les erreurs  
   - applique les règles de sécurité  
   - affiche un menu dynamique  
   - log les actions  
   - vérifie les dépendances  
   - valide les entrées  

>Tu passes d’un script simple à un framework.

---

### 🛡️ 3. Système de sécurité
- automatique : *security_check.sh*

>Un script qui scanne tous les scripts :

   - recherche eval  
   - détecte les commandes dangereuses  
   - vérifie les permissions  
   - valide les headers obligatoires  
   - génère un rapport de sécurité
