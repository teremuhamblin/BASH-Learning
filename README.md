# 📘 BASH-Learning
> **v1.0**

Projet d'entraînement Bash simple et pédagogique.

### Contenu
- *training.sh* : script interactif pour apprendre les bases
- *aliases.sh* : pack d'alias utiles pour accélérer le travail
- *exercices/* : exercices pratiques

### Utilisation
```bash
chmod +x training.sh
./training.sh
```

Objectifs
- Comprendre les variables
- Utiliser les fonctions
- Manipuler les menus interactifs
- S'entraîner avec des commandes système
